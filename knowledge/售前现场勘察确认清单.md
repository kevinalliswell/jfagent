# 机房售前现场勘察确认清单

报价前必须确认的现场条件，按优先级排列。每一项的缺失都会直接影响方案口径或带来交付风险。

## P0 — 直接决定方案与报价

1. **机柜规模与单柜功率**：计划机柜数、现有/新增服务器数量、单柜目标功率（决定 UPS 与制冷容量）。
2. **机房面积与平面**：长宽尺寸、柱网位置、净高（含梁下高度）、可用墙面。
3. **所在楼层与承重**：楼层、楼板设计活荷载（向物业/设计院索取）、电池与 UPS 集中区是否需要结构复核。
4. **UPS 后备时间要求**：15/30/60/120 分钟档位；≥120 分钟且非一层时触发承重红线。
5. **供电条件**：市电进线路数与容量、变压器余量、是否需要电力增容报装（周期常达 1~3 个月）。
6. **预算区间**：用于匹配配置档位与品牌档位，避免方案反复。

## P1 — 影响交付可行性与成本

7. **运输通道**：电梯轿厢尺寸（高×宽×深）与载重、门洞尺寸、走廊转弯半径；2 米级设备能否进场。
8. **室外机位置**：楼顶/外墙/地面，与机房的管长与高差，支架与穿墙条件。
9. **改造项目割接窗口**：业务可中断时间段、是否需要临时供电/临时制冷过渡。
10. **原机房现状**（改造/搬迁）：可利旧设备清单（机柜/UPS/空调/桥架）、拆除范围、旧电池处置。
11. **消防对接**：大楼消防主机品牌与联动接口、当地消防报审要求。

## P2 — 影响细节设计

12. 品牌偏好与禁用品牌（国产优先/进口优先/指定品牌入围）。
13. 网络出口与运营商光缆引入路由。
14. 监控值班模式（7×24 有人/无人值守）→ 决定动环告警方式。
15. 验收标准与质保期要求（第三方检测/甲方验收；1~3 年质保）。
16. 工期要求与里程碑（开工条件、停电配合、竣工节点）。

## 典型风险触发组合（向客户主动提示）

- 楼层 ≥ 2 + 后备时间 ≥ 120 分钟 → 楼板承重风险（P0 阻塞，必须结构复核）。
- 楼层 ≥ 2 → 设备运输风险（核实电梯与通道，预留吊装费）。
- 预算上限 < 参考估算 × 1.3 → 预算错配风险（准备可靠性优先/预算优先两档方案）。
- 单路市电 + 高可用要求 → 建议柴油发电机或加大后备时间。
- 室外机管长/高差超限 → 改水冷/氟泵机型或调整室外机位置。
