# 机房等级标准与设计规范要点（GB 50174-2017）

## 数据中心分级

GB 50174-2017《数据中心设计规范》将数据中心划分为 A、B、C 三级：

- **A 级（容错型）**：电子信息系统运行中断将造成重大经济损失或公共场所秩序严重混乱。典型行业：金融、国家级信息中心、大型云数据中心、三甲医院核心机房。基础设施按容错（2N 或等效）配置，任何单点故障或单次维护不应导致系统中断。
- **B 级（冗余型）**：系统中断将造成较大经济损失或公共场所秩序混乱。典型行业：地市级政务、高校、大中型企业、二级医院。基础设施按冗余（N+1）配置。
- **C 级（基本型）**：不属于 A、B 级的场合。基础设施按基本需求（N）配置，保证在正常运行情况下连续工作。

中小型机房改造与新建项目，行业常见做法是按 **B 级或 C 级**口径报价，关键子系统（UPS、空调）按 N+1 预留。

## 主要环境与建筑要求

- 主机房温度（冷通道/送风）：18~27℃，推荐 23±1℃；相对湿度 8℃露点至 60% RH。
- 楼板等效均布活荷载：主机房 ≥ 8 kN/m²（电池室建议 ≥ 16 kN/m²，UPS 及电池集中区域必须做结构复核）。
- 净高：建议 ≥ 2.6 m（架空地板下送风时按风量核算地板高度，常用 300~400 mm）。
- 机房不宜设在用水区域正下方，不应有与机房无关的水管穿越。
- 二层及以上机房必须复核：楼板承重、电梯轿厢尺寸与载重、运输通道宽度与转弯半径、门洞净尺寸。精密空调与一体化机柜整机高度普遍接近或超过 2 m。

## 供配电要点

- 双路市电引入为 B 级常见要求；单路市电时应配柴油发电机或加大 UPS 后备时间。
- UPS 容量按总 IT 负载 × 冗余系数（N=1.0，N+1≈1.25，2N=2.0）选型，并向上取整到标准容量档位。
- 末端配电：机柜双路 PDU（A/B 路），每路独立回路，回路负载率不超过 80%。
- 接地：联合接地电阻 ≤ 1Ω，机房内做等电位联结网格。

## 制冷要点

- 制冷量 =（IT 设备热负荷 + 建筑围护热负荷）× 1.1~1.2 安全系数。
- 中小机房常用风冷型精密空调；单柜功率 ≥ 8 kW 时建议封闭冷通道或列间空调。
- 空调配置 N+1 冗余为 B 级常规口径；室外机位置、铜管长度与高差需现场确认。

## 消防要点

- 主机房应设气体灭火系统，中小机房常用柜式七氟丙烷（HFC-227ea）装置，按保护区容积核算药剂量。
- 设置吸气式或点型感烟+感温双重探测，联动断电、停空调、声光报警。
- 机房围护结构耐火极限 ≥ 1.0 h，防火门向疏散方向开启。
